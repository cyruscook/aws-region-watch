# AWS Region Watch

AWS Region Watch is a static directory of AWS partitions, regions, and related metadata. It displays console domains, authentication endpoints, preference endpoints, DNS details, and regional service listings.

It uses both published AWS data, and unpublished AWS data, to reveal upcoming regions and partitions that haven't yet been announced by AWS.
